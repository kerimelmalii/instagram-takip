# Instagram Takip

Sosyal medya içerik planı ve performans takibi. Projeler (örn. vitrinweb), haftalık/aylık görünüm,
içerik türü (Post/Hikaye), durum (Başlanmadı/Tasarlandı/Planlandı/Paylaşıldı), görüntülenme/beğeni/yorum ve notlar.

Bağımlılık yok: tek `index.html` + PWA dosyaları. Veriler telefonda (localStorage) saklanır; menüden JSON yedek alınabilir.

## Telefona kurulum
1. Klasörü HTTPS bir yere yükle (GitHub Pages, Netlify, Cloudflare Pages…).
2. Telefonda aç → iPhone: Safari > Paylaş > Ana Ekrana Ekle · Android: Chrome > Ana ekrana ekle / Uygulamayı yükle.

## Yerelde deneme
`python3 -m http.server 8123` → http://localhost:8123
